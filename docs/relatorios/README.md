# Relatórios Mensais — FinFVC
> Última atualização: 2026-07-04

## O que vai aqui

Snapshots mensais consolidados do estado financeiro da família Crismanis, gerados a partir do estado atual de `docs/financeiro/` e dos dados do FinFVC naquele momento.

## Convenção de nomenclatura

`AAAA-MM-relatorio.md` — exemplo: `2026-07-relatorio.md`.

## Regra de imutabilidade

Um relatório mensal, uma vez fechado, **não é editado retroativamente**. Se um erro for encontrado depois, ele é corrigido em uma nota no topo do próprio arquivo do mês ("Correção posterior: ..."), preservando o que foi originalmente registrado — a integridade histórica importa mais que a estética.

## Estrutura sugerida de cada relatório

```
# Relatório — [Mês/Ano]

## Resumo do mês
## Receitas
## Despesas
## Patrimônio (variação)
## Dívidas (variação)
## Metas — progresso
## Decisões do mês
## Pontos de atenção para o próximo mês
```
