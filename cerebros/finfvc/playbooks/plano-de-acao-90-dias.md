# Playbook — Plano de Ação de 90 Dias
> Última atualização: 2026-07-04

## Abrir um novo ciclo

1. Revisar o diagnóstico atual (`../financeiro/diagnostico-atual.md`) e as metas ativas (`../financeiro/metas.md`).
2. Selecionar até 5 objetivos prioritários para os próximos 90 dias.
3. Para cada objetivo, definir ações concretas, responsável e prazo.
4. Definir critério de sucesso claro para cada ação.
5. Registrar o ciclo em `../financeiro/plano-90-dias.md`.

## Durante o ciclo

- Acompanhar progresso mensalmente, como parte do `fechamento-mensal.md`.
- Ajustar ações (não os objetivos centrais) se a realidade mudar significativamente — registrar o ajuste.

## Fechar o ciclo

1. Avaliar honestamente o que foi cumprido e o que não foi.
2. Entender por que algo não foi cumprido (falta de tempo, prioridade mudou, obstáculo não previsto) — sem essa reflexão, o próximo ciclo repete os mesmos erros.
3. Registrar o resultado na tabela de histórico em `../financeiro/plano-90-dias.md`.
4. Usar o aprendizado para definir o próximo ciclo — nunca recriar a lista do zero ignorando o ciclo anterior.
