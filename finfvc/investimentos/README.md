# Investimentos — FinFVC
> Última atualização: 2026-07-04

## O que vai aqui

Política, alocação-alvo, laboratório de simulação e material de referência por classe de ativo para as decisões de investimento da família Crismanis.

## Ordem de leitura recomendada

1. [politica-de-investimentos.md](politica-de-investimentos.md) — regras gerais.
2. [alocacao-alvo.md](alocacao-alvo.md) — como o patrimônio deveria estar distribuído.
3. [checklist-antes-de-investir.md](checklist-antes-de-investir.md) — checklist obrigatório antes de qualquer aporte.
4. [laboratorio-de-investimentos.md](laboratorio-de-investimentos.md) — onde toda oportunidade é simulada antes de virar decisão real.
5. Arquivos por classe de ativo (`tesouro-direto.md`, `renda-fixa.md`, `fundos-imobiliarios.md`, `acoes.md`, `etfs.md`, `previdencia.md`, `dolar-e-exterior.md`, `cripto.md`) — referência e critérios específicos.

## Regra central

Nenhuma decisão de investimento é tomada sem passar pelo [laboratório](laboratorio-de-investimentos.md) e sem checar o [checklist antes de investir](checklist-antes-de-investir.md). Isso vale mesmo para oportunidades que "parecem óbvias".
