# Relatórios — FinFVC
> Última atualização: 2026-07-04

## O que vai aqui

Snapshots periódicos consolidados do estado financeiro da família Crismanis: relatórios mensais (`template-relatorio-mensal.md`) e fechamento anual (`template-fechamento-anual.md`).

## Convenção de nomenclatura

- Mensal: `AAAA-MM-relatorio.md` — exemplo: `2026-07-relatorio.md`.
- Anual: `AAAA-fechamento-anual.md` — exemplo: `2026-fechamento-anual.md`.

## Regra de imutabilidade

Um relatório, uma vez fechado, **não é editado retroativamente**. Correções posteriores viram uma nota no topo do próprio arquivo ("Correção posterior: ..."), preservando o que foi originalmente registrado.
