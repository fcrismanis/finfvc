# Decisões — FinFVC
> Última atualização: 2026-07-04

## O que vai aqui

Um arquivo por decisão financeira relevante da família Crismanis, seguindo o [template padrão](template-decisao.md). Este diretório é a fonte de verdade histórica e auditável de "o que foi decidido, quando, e por quê".

## Convenção de nomenclatura

`AAAA-MM-DD-nome-curto-da-decisao.md` — exemplo: `2026-07-04-criacao-cerebro-financeiro-finfvc.md`.

## Regras

1. Toda decisão relevante (movimento de capital, mudança de estratégia, aceitação/recusa de oportunidade de investimento) gera um arquivo aqui.
2. Decisão registrada nunca é apagada. Se revista, cria-se novo registro referenciando o anterior.
3. Decisões de investimento seguem o modelo de comitê descrito em `../agentes/comite-de-investimentos-ia.md` antes de virarem registro final.
4. Decisões com data de "Revisar em" definida devem ser reavaliadas nessa data — o resultado da reavaliação também vira registro (mesmo que seja "mantida sem alteração").
