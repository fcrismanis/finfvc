## Como usar este inventário

1. Preencher primeiro este arquivo — ele é o mapa de onde buscar cada dado.
2. A partir dele, seguir para `questionario-patrimonial.md`, `questionario-despesas.md` e `questionario-investimentos.md` para aprofundar cada área.
3. Sempre que um item aqui mudar (nova conta, conta encerrada, cartão cancelado), atualizar este arquivo primeiro — ele é a fonte de verdade estrutural, os demais arquivos financeiros (`../financeiro/`) derivam dele.
